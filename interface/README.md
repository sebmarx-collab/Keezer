# Interface tactile — maquettes

A3 prépare l'écran d'accueil, les vues détaillées des deux fûts, les réglages LED, la calibration vide/plein, le compteur filtre et les défauts capteurs.

L'interface doit fonctionner avec la télémétrie simulée avant le choix final du matériel tactile. Le schéma `docs/architecture/CONTRAT_DONNEES.yaml` est provisoire.
