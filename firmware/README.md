# Firmware — état de préparation

**Aucun firmware matériel actif n'a encore été intégré.** A2 proposera une architecture ESP32 modulaire après choix de carte. Prévoir des abstractions pour les deux balances, la température, la pression basse CO₂, le débit eau, les LED et la liaison avec l'UI.

Commencer par des données et capteurs simulés, sans broches GPIO ou relais de compresseur pilotés. Les premières tâches sont dans `docs/missions/MISSIONS_INITIALES.md`.
