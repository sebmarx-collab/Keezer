# Démarrer les agents

1. Consulter le dépôt, puis `AGENTS.md` et `docs/gouvernance/CONTEXTE.md`.
2. Choisir une issue KZR-XXX dans GitHub.
3. Donner à Codex/ChatGPT Work la fiche `agents/A*.md` correspondante.
4. Réaliser le travail sur une branche de mission sans modifier les décisions acquises.
5. Faire relire, ajouter les résultats des tests et proposer une PR.
6. Obtenir l'accord du propriétaire avant intégration finale.
